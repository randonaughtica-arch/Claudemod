# Claude Mod Menu

A mod menu with level, editor and general hacks.

Open it with **Tab** (rebind it in the mod's settings), or with the round **M** button in the pause menu, the editor pause menu and the main menu.

## Level
- **Noclip**: the player can't die
- **Safe Mode**: progress and completions are never saved
- **Auto Safe Mode**: Safe Mode turns on by itself while Noclip, Speedhack or No Mirror is on (on by default)
- **Show Hitboxes**: hitboxes outside practice mode
- **Accurate Percentage**: percentage with two decimals
- **No Death Effect**, **Hide Attempts**, **Hide Pause Button**
- **No Mirror**: mirror portals don't flip the screen
- **Info Overlay**: FPS, clicks per second and attempt number
- **Speedhack**: game speed from 0.1x to 10x (music keeps its normal speed)

## Editor
- **Verify Hack**: upload without verifying
- **No (C) Mark**: removes the copy mark when uploading
- **Copy Hack**: copy any online level
- **Free Scroll** and **Zoom Bypass**

## Other
- **Unlock Icons**: use every icon and color
- **Practice Music**: the level's song plays in practice mode
- **No Transition**: no fade between menus

Every toggle is also in the mod's Geode settings page.
